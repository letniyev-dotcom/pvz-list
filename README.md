# ПВЗ лист — Android (Kotlin + Jetpack Compose)

Только release-сборка. Debug-вариант отключён.

## Как получить APK
1. Залей содержимое этого архива в репозиторий GitHub (ветка `main`).
2. Открой вкладку **Actions** → workflow **Build release APK** запустится сам
   (или нажми **Run workflow**).
3. По завершении скачай APK из **Artifacts** → `pvz-list-release-apk`.

Чтобы APK ещё и появился в **Releases**, поставь тег:
`git tag v1.0 && git push origin v1.0`

## Подпись
Релизный ключ: `app/release.jks` (alias `pvz`), пароли прописаны в `app/build.gradle.kts`.
Держи репозиторий приватным и сохрани копию ключа: им нужно подписывать все обновления.

## Шрифт
Onest скачивается в CI в `app/src/main/assets/fonts/onest.ttf`.
Если положишь этот файл в репозиторий сам — будет использован он.

## Вход через Telegram (TDLib)
Вход настоящий: номер → код из Telegram → облачный пароль (если включён).
Сессия хранится в приватной папке приложения, после перезапуска вход не нужен.
`api_id` и `api_hash` лежат в `app/src/main/java/ru/pvzlist/app/Tg.kt` — репозиторий должен быть приватным.
Библиотека `com.github.tdlibx:td` приходит с JitPack. Если первая сборка в Actions упала
с таймаутом на jitpack.io — просто нажмите **Re-run jobs**: JitPack при первом обращении собирает пакет.

## Отчёты, группы и темы (v1.1)
Как в html: после открытия смены на экране «Сегодня» лежит карточка «Приёмка» (с таймером ночной приёмки)
и карточки «Красные возвраты», «Закрытие коробки», «Перерыв». Нажали карточку — открылся экран отчёта:
выбор маркетплейса, фото или скриншот, «КВ есть / КВ нет», комментарий и предпросмотр сообщения.

Группы и темы берутся прямо из аккаунта Telegram (TDLib), отдельно для Ozon и Wildberries:
- при первом входе сразу открывается «Куда отправлять», дальше туда же можно попасть из профиля («Группы и темы»)
  или нажав на плашку группы в самом отчёте;
- в списке только группы (каналы не показываются), есть поиск; для групп с темами темы подгружаются
  и подбираются по названию автоматически (приёмка, красные, коробка, перерыв), любую можно поменять;
- отчёт уходит от вашего аккаунта в нужную тему (или в общий чат, если тем нет), фото уходит с подписью;
- выбор и адреса запоминаются на телефоне, что отправлено за смену — тоже (сбрасывается в 21:00).

Адреса Ozon и WB вводятся в профиле, пока адрес пустой — отправить отчёт нельзя.

Камера открывается через системное приложение, отдельное разрешение не нужно (в манифесте есть FileProvider).
